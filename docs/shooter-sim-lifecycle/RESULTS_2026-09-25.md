# Shooter SIM lifecycle run: September 25, 2026

This is the evidence for [P3.1 / H1](../IMPLEMENTATION_TRACKER_2027.md#p31--h1-one-shooter-child-update-per-robot-cycle). The temporary measurement code and its [reuse instructions](README.md) are separate from the final robot code.

Counters independently recorded completed robot cycles; hood, turret, and flywheel `periodic()` calls; each corresponding SIM `updateInputs()` call and 20 ms model step; and turret `periodicAfterScheduler()` calls. At both endpoints of every interval below, **all eleven counters equaled the listed robot-cycle value**. Thus each counter increased by exactly 100 and each SIM model advanced 2.0 simulated seconds. Transition cycles were excluded.

| Scenario | Completed cycles | Mode and command evidence |
| --- | --- | --- |
| Disabled | 7640 → 7740 | Operator identified this interval as Disabled. The first probe did not print Driver Station mode, so this label is operator-reported. |
| Teleoperated, idle | 1160 → 1260 | `DS_MODE=TELEOP`, `OP_RB=false`, `TRACKING_SCHEDULED=false` at both endpoints and every 20-cycle snapshot between. |
| Shooter tracking | 1640 → 1740 | `DS_MODE=TELEOP`, `OP_RB=true`, `TRACKING_SCHEDULED=true` at both endpoints and every 20-cycle snapshot between. The flag checked the command bound to the operator right bumper. |
| After tracking release | 2120 → 2220 | `DS_MODE=TELEOP`, `OP_RB=false`, `TRACKING_SCHEDULED=false` at both endpoints and every 20-cycle snapshot between. |

The Disabled interval came from an earlier SIM run; the other three came from one subsequent run. The tracking command was scheduled by cycle 1620 and no longer scheduled by cycle 2080.

In the final probe-free SIM smoke check, the operator observed `AdvantageKit/RealOutputs/Turret/Mode` as `OPEN_LOOP` before pressing the right bumper, `CLOSED_LOOP` while pressing it, and `OPEN_LOOP` after release. These checks validate SIM callback counts and the observed command path; physical motor behavior and timing remain unmeasured.
